dek: The Connecticut code basis and how the code comparison is used.

The code basis is the **2022 Connecticut State Building Code**, which adopts the **2021 IECC with Connecticut
amendments**, for **Fairfield County, Climate Zone 5A**. The
[Connecticut Office of the State Building Inspector](https://portal.ct.gov/en/das/office-of-state-building-inspector/connecticut-state-building-code/regulations)
publishes the adopted codes and amendments; the edition in force is set by the permit application date.

The project is an **alteration of an existing home with an addition**. The code treats the addition, the altered
assemblies and the retained construction under separate provisions, and the architect sets the compliance path for
each: the exposed wall and roof cavities, the replacement windows, the roof work and the sunroom.

The model's **Code Minimum** variant is a whole-building energy benchmark built from the new-construction
prescriptive values (windows at about U-0.27, 3.0 ACH50). It gives the other variants a common reference; the
project's actual code filing follows the existing-building provisions above.

Connecticut's [amendment to R502.3.1](https://portal.ct.gov/-/media/DAS/Office-of-State-Building-Inspector/2022-State-Codes/2022-CSBC-Final.pdf#page=105)
exempts the addition from blower-door testing and accepts visual verification of the air-barrier and insulation
details instead. The **1.0 ACH50** target in this report is therefore a performance recommendation and a
contractual one, and it belongs in the construction documents as an added requirement.
