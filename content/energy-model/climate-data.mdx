title: Climate Data
dek: The Greenwich, Connecticut climate data driving the model.
---

The energy model uses the PHI climate data set for **Greenwich, Connecticut**, the closest station to the site.
PHI classifies the location as **cool-temperate**, and the building code places it in **Climate Zone 5A**. The two
systems describe the same weather for different purposes: the PHI class sets the Passive House component targets,
and the code zone sets the prescriptive code minimums.

Monthly mean outdoor temperatures run from about **29°F in January to 74°F in July**. PHPP combines these
monthly temperatures and solar radiation with the building geometry, shading and occupancy to calculate annual
heating and cooling demand. The monthly averages come from the same local weather records as the hourly data
used by other US energy programs; the [Resilience](/resilience/) assessment uses the full hourly weather for its
outage simulations.
